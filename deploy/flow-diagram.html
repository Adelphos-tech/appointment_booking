🛡️ What happens when things go wrong
1
Someone visits a page that doesn't exist
If a user types a wrong URL like /random-page, the app doesn't crash. It just shows the main page or redirects to login.
Wrong URL → No crash — handled smoothly
2
Someone's login expires
If your login token becomes invalid (expired or tampered with), the app automatically detects it when it tries to load data. It clears your login and sends you back to the login page. You won't be stuck on a broken page.
Token expired → App detects it → Clears login → Sends to Login page
✅ User is safely redirected to login
3
Unapproved user tries to log in
If a company owner registers but hasn't been approved yet, and they try to access the dashboard, the app kicks them back to login. This prevents unapproved people from seeing anything.
Pending user → Tries to access dashboard → Sent back to login
4
Mobile phone view
The app works on mobile phones too. On small screens, the sidebar turns into a hamburger menu. Everything should fit without horizontal scrolling.
📱 Hamburger menu appears 📱 No horizontal scroll 📱 Everything fits on screen
✅ Safety & error handling complete
